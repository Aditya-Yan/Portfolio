# React Bits — Waves

Waves.jsx and Waves.css are the actual React Bits component downloaded from:
https://github.com/DavidHDev/react-bits/tree/main/src/content/Backgrounds/Waves

Retrieved November 8, 2026 (America/Chicago). The upstream license is retained in LICENSE.md.
The component source is unmodified. main.jsx supplies the portfolio's ocean colours, motion
controls, reduced-motion preference, and pauses the background while a section panel is open.

Rebuild the committed static assets after editing:

```sh
npm ci
npm run build:effects
```

Normal preview still only needs `python3 -m http.server 8000`.
